## 功能

### 界面与外观

- **导航**：首页 / 历史 / 资源 / 下载 / 我的，追剧从侧栏和电视端进入。手机用液态玻璃胶囊底栏，平板和电脑用侧栏（可收起），电视用顶部 Tab；宽屏的子页面在侧栏右侧打开。
- **界面模式**：自动识别、电视、手机、平板、窗口（只有电脑提供）；手动选定后不随窗口宽度切换。电视模式强制横屏，手机模式锁定竖屏。
- **主题**：跟随系统取色（Android 12+ 跟随壁纸，Windows 和 macOS 跟随强调色）或 6 个预设色板；浅色 / 深色 / 跟随系统。

### 浏览

- **首页**：顶部有「站源 / 文件源」分段开关，站源模式下点站源名切换站源；切到文件源模式整页换成文件源列表，可浏览网盘 / WebDAV 里的视频直接播放。站源模式：分类 Tab 依次为推荐 / 全部 / 各榜单 / 各题材，榜单封面标出名次。第一个 Tab 顶部大卡片显示最近看过或推荐的剧。滑到底自动加载，下拉或「刷新」重新拉取当前分类。
- **搜索**：只搜当前站源，保留最近搜索；部分站源有输入联想。
- **详情**：封面模糊作底，显示集数、完结状态、分类、播放量、标签和简介；选集每组 30 集，落在续播那一集，看过的集变浅，VIP 集有标记。打开时后台预缓冲续播集。

### 播放

| 设备 | 体验 |
| --- | --- |
| 电脑 | 左边视频、右边选集栏，可宽屏、全屏；悬停弹出清晰度、倍速、音量；支持空格、Enter、方向键、Page Up / Page Down、M 等快捷键 |
| 手机 | 竖屏短剧沉浸式，上下翻页切集，左右滑快进快退，长按画面打开「播放设置」（画面调节、A-B 循环、截图、多音轨、字幕延迟等）；长按加速（默认 2 倍，可在设置里改）后把手指拖到屏幕最下方可锁定倍速，松手不恢复。横屏视频竖拿时视频在上、简介 / 选集在下，转横屏自动全屏；全屏双击两侧快退 / 快进，左半屏上下滑调亮度，右半屏调音量 |
| 平板 | 横着拿同电脑，竖着拿同手机，全屏期间锁定横屏 |
| 电视 | 播控浮在画面上，隐藏时左右键快退 / 快进 10 秒；返回键依次关闭选项、收起播控、退出；换集回详情页选 |

所有设备通用：下一集提前缓冲，翻页和连播直接接上；倍速、清晰度和弹幕开关会记住。设置里可开「默认静音播放」，每次进播放先静音。在线播放有弹幕，本地播放不加载。

iOS 画中画是会话保活：开小窗后播放页退回详情页，视频只留在小窗里播，不再和小窗同播；点小窗还原会平滑推回播放页，在详情页再点同一部剧接回小窗进度，点别的剧才结束小窗。

### 追剧与记录

- **追剧**：只分追 / 不追。有新集的剧排在「有更新」并标出更新集数；可搜索、按站源筛选、多选取消。后台每 30 分钟检查一批未完结的追剧。
- **观看记录**：按今天 / 昨天 / 更早分段；只显示当前站源的记录，切换站源自动跟着变；可搜索、多选删除，「清空」只清当前列出的记录。
- **我的**：用户卡、最近观看和设置入口；正在下载的集数显示在底栏 / 侧栏「下载」图标的角标上。

### 下载

- 详情页「下载选集」或播放页选集栏多选（点选、拖选、全选）。
- 下载页（底栏「下载」）分「下载中」「已下载」「合并」，可单集或全部暂停 / 继续 / 重试；已下载按剧显示，可播放、删除、补齐缺集。
- 每集下载完自动转成普通 mp4（红果先解密，m3u8 合成一个文件），保存为 `下载目录/剧名/第 N 集.mp4`，可以直接拷出使用。
- 旧版下载的分集保持原样，旧版合并出的文件不再列出。电视端不提供下载。

### 设置、用户与备份

- **设置**：外观、播放、弹幕、下载、存储、代理、用户、关于、诊断 9 组，改动立即保存；没有权限的项置灰并注明原因。
- **用户**：多用户独立保存追剧、记录和搜索，轻点即切换；管理员可添加、编辑、删除用户，设置能访问的站源和是否允许下载。
- **备份**：导出 / 恢复用户、追剧、观看记录和偏好设置（含主题色），已下载视频不受影响；旧版备份仍可导入。本地配置损坏时启动页可从备份恢复。

## 安装

在 [Releases](../../releases) 下载对应平台的包，文件名以 `lvguo-` 开头。

| 平台 | 安装包 |
| --- | --- |
| Android 7.0+ | arm64-v8a / armeabi-v7a / x86_64 三种 APK，按设备架构选择（大多数手机选 arm64-v8a）；同一签名可覆盖升级，旧证书版本需卸载重装 |
| Windows 10/11 x64 | 安装包 `*-setup.exe`，默认安装到当前用户、无需管理员权限；或便携 ZIP，解压后运行 `lvguo.exe`，保留所有 DLL 与 `data` 目录；便携版的设置、记录、缓存和默认下载都存在程序旁的 `userdata` 目录，删掉该目录则改回存到系统用户目录 |
| iOS 15.1+ | 未签名 IPA，需自行签名或用 iloader 等工具侧载 |
| macOS 12+ | 通用 dmg（Apple 芯片与 Intel），打开后拖入「应用程序」；未经公证，首次打开前需解除隔离（见下方） |

> [!TIP]
> Android 安装提示 `INSTALL_FAILED_NO_MATCHING_ABIS` 表示 APK 与设备架构不匹配，请换对应架构的安装包。

> [!IMPORTANT]
> macOS 首次打开前在终端执行：
>
> ```sh
> xattr -dr com.apple.quarantine /Applications/绿果视频.app
> ```

## 使用说明

### 首次打开

1. 逐条勾选使用条款，15 秒后可以继续。
2. 默认只有一个「管理员」用户，拥有全部权限，不设密码。
3. 安装包不带站源，先在 **资源** 页手动安装模块（见下），装好后打开 **首页** 就能看。

### 站源模块

站源是应用访问某个网站的适配代码，打包成模块（`.zip`）单独安装、更新和卸载，应用本体不再自带站源。新增或修复站源只需更新模块，不用等应用发版。

在 **资源** 页管理（底栏有入口；首页切换站源的面板里也有「管理站源」）。资源页分两组：

| 分组 | 用途 |
| --- | --- |
| 站源 | 开关、卸载站源，点卡片查看站源会访问的域名；组头「+ 添加」走手动安装：「选择本地文件」安装 `.zip` 模块，或「输入下载地址」填模块 zip 的链接。随安装包附带的内置模块也列在这里（当前版本没有附带模块） |
| 文件源 | 组头「+ 添加文件源」挂载天翼云盘、中国移动云盘（WebDAV 挂载，或 App 内打开官方网页登录的原生模式，实验）、WebDAV 服务器、FTP 服务器或 HTTP 直链；逐层浏览文件夹，视频文件点开直接播放，进度自动续播，观看记录在历史页「文件源」模式里查看 |

- 只能安装模块，不能直接填网站网址；没有对应模块的网站无法添加。想要新站源可以开 Issue 建议，或按 [DEVELOPMENT.md](DEVELOPMENT.md) 的站源模块说明自己编写模块。
- 模块文件由应用自己保存在数据目录的 `modules` 文件夹（Windows 为 `%APPDATA%\<包名>\modules`，便携版为程序旁的 `userdata\modules`），不需要手动放文件。
- 卸载站源会保留它的追剧、观看记录和下载，重新安装后恢复显示。
- 手动安装的模块未经任何商店收录，只装可信来源的。

### 浏览与搜索

- 点首页顶部的站源名切换站源，切换后分类和搜索都针对当前站源。
- 分类较多时点分类栏右侧的「全部分类」按钮选择；各分类的内容和排序由站点决定。
- 不想让别人看到封面：**设置 › 外观** 打开主页的模糊封面按钮，可设为开屏自动模糊限制级或全部封面。

### 播放与下载

- 各设备的手势和快捷键见上方 [播放](#播放)；手机长按画面打开「播放设置」，里面有弹幕样式、小窗播放和投屏（iOS 不提供投屏）。
- iPhone 和 iPad 可点播放器的「画中画」按钮打开系统小窗：播放页随即退回详情页，视频只在小窗里继续播；点小窗还原会回到播放页并接上进度。也可在 **设置 › 播放** 开启「离开应用时自动小窗」。
- 倍速、清晰度、解码方式、手势开关在 **设置 › 播放**，弹幕字号、显示区域、屏蔽词在 **设置 › 弹幕**。
- 下载目录在 **设置 › 存储** 修改和迁移；Android 可在已下载的剧里「导出」到 `Movies`，或在 **设置 › 下载** 打开下载完成后自动导出。

### 多用户与权限

1. **设置 › 用户** 先给管理员设置密码，才能「添加用户」。
2. 编辑用户可设置密码、允许访问的站源和是否允许下载；普通用户看不到资源入口，没有权限的设置项置灰。
3. 管理员打开「启动时需要登录」后，每次打开应用先选择用户并输入密码；有密码的用户可用「锁定当前用户」回到登录页。

### 备份与迁移

**设置 › 诊断** 导出 / 恢复备份，备份包含用户、追剧、观看记录和偏好设置；站源模块不在备份里，恢复后请手动重新安装；已下载的视频不在备份里，需要单独拷贝下载目录。

### 常见问题

- **首页提示「还没有安装站源」**：到 **资源** 页手动安装（选本地文件或填下载地址）；普通用户请让管理员安装并开放站源。
- **某个站源加载失败或很慢**：先下拉刷新或在 **设置 › 代理** 换连接方式（自动 / 直连 / 手动代理，支持 HTTP、HTTPS、SOCKS5），再确认模块是否为最新版（有新版时手动安装新版模块）。
- **有声音没画面、卡顿**：**设置 › 播放 › 解码方式** 换成兼容方式；Android 仍无画面再打开同组的「兼容渲染模式」。
- **反馈问题**：开 Issue 时写明应用版本（**设置 › 关于**）、平台、站源和操作步骤；播放问题附上 **设置 › 诊断 › 播放调试日记** 里复制的日志。

## 检查更新与隐私

检查更新只读取最新版本号，**不发送任何数据**。启动时检查一次，有新版时每次启动都会提示，可选择忽略此版本或不再提醒。

应用不做使用统计：早期版本有过的匿名统计上报已整套删除。应用不发送观看记录、追剧、搜索、站源设置或其他任何数据。
